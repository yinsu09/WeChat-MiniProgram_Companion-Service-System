# 陪伴服务系统 · 答辩录制稿（约 3–4 分钟）

> 语速建议：中等偏慢。全文按「用户端 → 服务人员端 → 管理端」顺序写，便于边讲边操作。  
> 括号内为画面提示，录制时不必念出。

---

各位老师好，我是（姓名），学号（学号）。本次课程设计完成的是**陪伴服务微信小程序**，下面按用户端、服务人员端、管理端三个端口，依次介绍系统功能。

---

## 一、用户端（约 90–100 秒）

（画面：登录页 → 首页 → 服务列表/详情 → 下单 → 订单 → 评价/积分）

首先是**用户端**。用户登录后进入首页，可以看到陪诊、陪护、陪玩、陪吃、陪游等多种服务类型，也可以搜索或按条件筛选服务。

进入某个服务详情后，用户可查看价格、时长、可预约时段，选择预约日期和地点，并指定服务人员，或由系统自动匹配。确认信息后提交订单并完成支付，订单进入待接单状态。

在「我的订单」中，用户可查看待支付、待服务、服务中、已完成等不同状态的订单；支持取消订单、申请退款，多次卡订单还可以预约下一次服务。服务完成后，用户可对服务人员进行多维度评分与文字评价。

此外，用户还有积分与优惠券功能：消费可获得积分，可在积分商城兑换优惠券，下单时选择优惠券抵扣；也可以查看消息通知，及时了解订单状态变化。

---

## 二、服务人员端（约 60–70 秒）

（画面：服务人员登录 → 工作台 → 订单处理 → 我的服务 → 收入/评价）

接下来是**服务人员端**。服务人员登录后进入工作台，可以看到待接订单、今日收入、评分等概览信息。

在订单页面，服务人员可对系统分配或用户指定的订单进行接单或拒单；接单后可开始服务、暂停或恢复服务，结束后提交完成。拒单时需填写原因，系统会重新派单。

服务人员还可以管理「我的服务」：发布或编辑可提供的服务项目，设置价格、可服务日期与时段、服务区域；也可以设置工作或休息模式。服务完成后，可查看用户评价，并对用户进行反向评价；同时能查看个人收入与历史服务记录。

---

## 三、管理端（约 60–70 秒）

（画面：管理员登录 → 后台首页 → 服务管理 → 人员管理 → 订单/派单 → 退款售后 → 营销/统计）

最后是**管理端**。管理员登录后台后，可看到平台订单量、用户数、营收等统计概览。

在服务管理中，可维护服务类型与具体服务项目，设置价格、上下架状态等。在人员管理中，可审核、启用或禁用服务人员，并配置服务等级规则，系统会根据完成单量与评分自动调整等级。

在订单管理中，管理员可查看全部订单，对未分配人员的订单进行人工派单，也可处理异常订单。在退款与售后模块，可审核用户的退款与投诉申请，同意或拒绝并填写说明。

营销管理支持优惠券、组团游、新手礼包、限时折扣等活动配置；数据统计可查看热门服务、人员排行、用户消费与营收等情况，方便了解平台运营状态。

---

## 结尾（约 15–20 秒）

（画面：回到首页或功能模块总览）

以上就是本系统三个端口的主要功能。整体形成了「用户下单 → 人员服务 → 评价反馈 → 后台监管」的完整闭环。我的介绍到此结束，谢谢老师！

## 录制切屏对照（边讲边演示）

| 讲述段落 | 建议操作顺序（连贯演示） |
|----------|--------------------------|
| 用户端开头 | 登录 → 首页浏览服务类型 |
| 浏览与下单 | 点进服务详情 → 选时间/人员 → 提交订单 → 支付 |
| 订单与评价 | 我的订单（切几个状态）→ 评价页 → 积分/优惠券页（可选） |
| 切换角色 | 退出，进入服务人员登录 |
| 服务人员端 | 工作台 → 待接订单 → 接单/开始服务 → 我的服务列表 |
| 切换角色 | 退出，进入管理员登录 |
| 管理端 | 后台首页 → 服务管理 → 人员管理 → 订单派单 → 退款审核 → 营销或统计（选 1～2 个点一下即可） |
| 结尾 | 切回用户首页或总览页 |

**时长控制**：若超过 4 分钟，可省略用户端「积分商城」和服务人员端「反向评价」各一句；若不足 3 分钟，在管理端多演示一次人工派单或退款审核。
